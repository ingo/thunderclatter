# Thunderclatter

Landing page for Thunderclatter: we make mobile apps for fun. A static site (`index.html`, `style.css`,
`assets/thunderclatter.png`), no build step. The logo is an 100x100 pixel-art PNG, scaled with nearest-neighbour.
Serve it from any static host, e.g. GitHub Pages.
The wordmark (`assets/title.png`) is generated by `scripts/make-title.py` from a custom 7x9 bitmap font.
